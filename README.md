Scenario:- Managing a Remote Repository for a Web Project
----------------------------------------------------------

You have completed the initial version of a web application on your local system. Now, you need to store the project on GitHub so that it can be backed up and shared with your team.

After uploading the project, you will perform common Git remote operations such as Push, Fetch, Merge, Pull, Reset, Revert, Clone, and Fork to understand how developers collaborate using local and remote repositories.

Steps:-
=====

1. Create a local Git repository.

2. Create a GitHub repository and connect it to the local repository.

3. Push the local project to GitHub.

4. Make changes in the remote repository and fetch them into the local repository.

5. Merge the fetched changes into the local branch.

6. Perform a pull operation to update the local repository.

7. Use Reset to undo local commits.

8. Use Revert to undo a committed change while preserving history.

9. Clone the remote repository into another local folder.

10. Fork a public GitHub repository into your own GitHub account and clone the fork.
